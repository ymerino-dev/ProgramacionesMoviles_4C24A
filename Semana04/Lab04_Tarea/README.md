## Descripción del Proyecto
Esta aplicación es la implementación base del Laboratorio 04, desarrollada manualmente siguiendo la guía oficial. El objetivo principal es aplicar los conceptos de **Manejo de Estados en Jetpack Compose**.

Se utilizaron las siguientes herramientas principales:
* `remember` y `mutableStateOf` para gestionar el estado del texto ingresado por el usuario y el contador de IDs numéricos.
* `mutableStateListOf` para gestionar dinámicamente la colección de tareas, permitiendo que la interfaz (UI) se recomponga automáticamente al agregar, marcar como completada o eliminar un elemento.
